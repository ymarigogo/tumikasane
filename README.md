# ツミカサネ

今週のがんばりを見える化して、自分にご褒美を。

「ツミカサネ」は、毎日の小さなタスクを積み重ねて、できたことを見える化するためのシンプルな習慣・タスク管理アプリです。

やることを登録して、できたら「できた！」を押すだけ。
1週間の達成率を確認したり、過去の達成状況を振り返ったりしながら、自分のペースでコツコツ続けられます。

さらに、あらかじめ自分でご褒美を5つ登録しておくと、達成したタスクの数に応じてご褒美ルーレットを回せます。

「もっと頑張らなきゃ」ではなく、

「これだけできた！」をちゃんと見つける。

そんな気持ちで、日々の小さな積み重ねを楽しむためのアプリです。


## 主な機能 ##

📝 タスク登録
今週やるタスクと見積もり時間を登録できます。

⏱️ 「できた！」チェック
完了したタスクを記録できます。

📊 今週の分析
1週間のタスク達成率をグラフで確認できます。

🏆 達成ログ
過去の週の達成状況を振り返ることができます。

🎁 ご褒美設定
自分で5つのご褒美を登録できます。

🎡 ご褒美ルーレット
タスクを達成すると獲得したスピンでルーレットを回せます。

## コンセプト ##
タスク管理は、「できなかったこと」を並べるためだけのものではありません。

小さな「できた！」を積み重ねて、
自分がちゃんと前に進んでいることに気づく。

「ツミカサネ」は、そんな前向きな振り返りを楽しむためのアプリです。
